# SB Utilities

Hypixel Skyblock QOL utilities mod for Minecraft 1.21.11 (Fabric).

## About

SB Utilities is a client-side Fabric mod built for Hypixel Skyblock. It adds a collection of quality-of-life features designed to reduce repetitive manual actions and give you better information while playing.

**HUD** — A draggable overlay showing live TPS, ping, FPS, and an optional real-world clock, all with configurable colors and transparency.

**Tool Swapper** — Automatically switches to the right tool in your hotbar when you start mining a block, then swaps back when you're done. Supports custom rules per block pattern and tool name, wildcard matching, and an optional inventory search.

**Weapon Swapper** — Automatically equips a matching weapon when a target entity is nearby or targeting you. Supports per-entity rules, wildcard matching, and an optional attack-on-swap to immediately strike with the new weapon.

**No Break** — Prevents you from accidentally breaking blocks. Supports a whitelist or blacklist of block patterns, per-tool rules (e.g. only block breaking gemstones when holding a Pickonimbus), and comma-separated block lists per rule.

**No Interact** — Prevents accidental right-click interactions with blocks or entities. Same rule system as No Break, with additional options to block item abilities and general item use.

**Wind Assist** — Tracks the wind direction shown in the Hypixel Skyblock scoreboard and optionally nudges your aim or arrow trajectory to compensate. Configurable speed, invert, and crouching/breaking conditions.
